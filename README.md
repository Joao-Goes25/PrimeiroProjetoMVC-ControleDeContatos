# Controle de Contatos 📞

Este projeto tem como finalidade principal o **aprendizado prático da arquitetura MVC (Model-View-Controller)** e o aprofundamento na linguagem **C#** com ASP.NET Core.

## 📌 Sobre o Projeto
O desenvolvimento deste sistema está sendo **baseado fielmente no tutorial do canal [Programador Tech](https://www.youtube.com/@ProgramadorTech)**, servindo como guia de estudos para entender a estrutura de um projeto web, manipulação de dados e boas práticas de desenvolvimento.

### ⚡ Alterações e Ajustes
Embora siga a estrutura do tutorial, o projeto possui **sutis alterações** e adaptações pessoais de layout, organização ou código feitas durante o processo de desenvolvimento para fixação do conteúdo (como ajustes de design usando Bootstrap, entre outros).
